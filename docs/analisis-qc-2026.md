# Análisis QC 2026 — Comunidad Java Indra Colombia

## Resumen ejecutivo

El QC 2026 evaluó a la comunidad Java de Indra Colombia y CA&C (~200 personas) en múltiples áreas técnicas. Los resultados muestran fortalezas consolidadas en fundamentos y brechas relevantes en áreas modernas de ingeniería de software.

---

## Brechas clave (prioridad descendente)

| Área | Score QC | Brecha | Impacto en el plan |
|------|----------|--------|--------------------|
| Azure DevOps | 60% | Alta | Paquete Micro+Cloud+DevOps |
| Hibernate / ORM | 64% | Alta | Paquete Hibernate/JPA |
| Cloud Azure | 76% | Media-Alta | Paquete Micro+Cloud+DevOps |
| SOLID + TDD | 77% | Media | Paquete SOLID+TDD |
| Spring avanzado | 77–83% | Media | Paquete Spring Web/Testing |
| Testing | 79% | Media | Paquetes SOLID+TDD y Spring |
| Microservicios | 86% | Media-Baja | Paquete Micro+Cloud+DevOps |

---

## Fortalezas (no priorizar en el plan)

- Java EE básico
- Spring básico (IoC, MVC básico)
- Hibernate básico
- SQL
- Git
- Maven
