# Week 02 — TDD con JUnit 5

**Fecha**: 2026-07-09 · **Paquete**: SOLID + TDD

## Objetivo

Practicar el ciclo **red → green → refactor** desde cero: escribir el test antes que el código y dejar que los tests guíen el diseño.

## Contexto técnico

**Brecha QC atacada**: SOLID + TDD (77%)  
TDD es la disciplina con mayor retorno de inversión en calidad. En esta sesión no se trata de cobertura — se trata de **diseñar con tests**.
